A simple Flutter application to calculate your exact age in years, months, and days.

---

## ✨ Features

- 📆 Calculate age from your birthdate.
- ⏱️ Displays years, months, and days clearly.
- 🧮 Simple and clean user interface.
- 🟢 Works offline — no internet required.

---

## 💡 Support

- Built using **Flutter** (cross-platform).
- No external database or API required.
